# Caladea fonts

These unmodified regular and bold fonts come from [Google Fonts](https://github.com/google/fonts/tree/13c010f766052c13fa9cc8c656008cee55fb4775/ofl/caladea), revision `13c010f766052c13fa9cc8c656008cee55fb4775`.

They are distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
Caladea is the Cambria-compatible font already used by the PDF generators.
Bundling it lets both scripts run without installing a system font package.
